> 🎶 A **Spotify Clone** built using HTML and CSS.  
> A static replica of the Spotify web interface for practicing layout, styling, and responsiveness.

---

## 🚀 **Overview**

This project is a **static clone of Spotify Web** that includes:  
- 🎧 Navigation sidebar with logo and menu items  
- 🖼️ Playlist section with album images  
- 📜 Song list with track titles and artists  
- 🖥️ Responsive layout for desktop screens  

This project is a great way to practice **HTML structure, CSS styling, Flexbox/Grid, and responsive design**.

---

## 🧰 **Tech Stack**

| Tech | Description |
|------|-------------|
| 🧱 HTML5 | Structure of navbar, playlist, and songs |
| 🎨 CSS3 | Styling, Flexbox/Grid layout, hover effects, and responsiveness |

---

## ⚙️ **How It Works**

1. The **sidebar** contains the Spotify logo, search, and menu items.  
2. The **main section** displays playlists, albums, and song lists.  
3. The layout uses **Flexbox** for sidebar and content alignment.  
4. All interactions (play buttons, hover effects) are **static** for now — it’s a frontend design clone.
